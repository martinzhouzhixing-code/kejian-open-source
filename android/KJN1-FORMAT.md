# KJN1 课堂转写/总结固定格式

`KJN1|ID|课程ID|课程日期|标题|总结|要点JSON|待办JSON|逐字稿|时长秒|创建时间|本地音频路径`

- 未知或未填写字段统一使用 `~`。
- `课程日期` 使用 `YYYY-MM-DD`；`创建时间` 使用 ISO-8601 UTC。
- 要点与待办是 JSON 字符串数组。
- `|`、反斜杠和换行分别转义为 `\|`、`\\`、`\n`。
- AI 和服务器只能返回前 11 个业务字段；第 12 个本地音频路径必须为 `~`，仅由手机写入。
- 云同步始终把第 12 个字段改为 `~`，服务器永不接收手机音频文件路径。

## AI 转写总结的内部输出协议

语音模型只负责生成逐字稿；总结模型只能返回 `KJN1-SUMMARY/2` JSON：

```json
{"protocol":"KJN1-SUMMARY/2","language":"zh-CN","title":"标题","summary":"总结","keyPoints":["要点"],"actionItems":["明确待办"],"uncertainties":["待确认内容"]}
```

- 字段、层级和类型固定，禁止增加字段或输出 JSON 之外的文字。
- 不得根据常识补写逐字稿中没有的结论、日期、作业和人名。
- 没有待办或存疑项时必须使用空数组，不得使用说明性占位文本。
- 服务器先校验协议；第一次不合格会携带校验错误重试一次，第二次仍不合格则任务失败且退还录音时长。
- `uncertainties` 会附加到 KJN1 的“总结”字段中，最终下发给手机的记录仍严格保持 12 个字段。
