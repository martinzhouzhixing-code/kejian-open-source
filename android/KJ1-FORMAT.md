# KJ1 课程固定格式

KJ1 是课间中每个课程模块的唯一交换表示。应用本地存储、复制粘贴、文件识别结果和未来 AI 输出都应先归一化为一行 KJ1，再由同一解析器生成课程模块。

```text
KJ1|ID|课程|课堂地址|教室|教师|星期|开始-结束|周次|颜色|单次日期|排除日期|提醒
KJ1|~|ENG|D楼|D207|~|周一|11:30-12:30|1-16|蓝色|~|~|是
```

规则：

- 一行必须恰好有 13 个字段，字段次序不能改变，也不能省略。
- `~` 是唯一空值占位符。用户没有填写或识别器无法确定时必须写 `~`。
- ID 为 `~` 时由应用生成；从应用复制或备份时保留原 ID。
- 星期只使用 `周一` 至 `周日`。时间使用 24 小时制 `HH:mm-HH:mm`，课程不可跨日。
- 周次使用 `1-16` 或 `1,3,5`。单次课程把周次写 `~`，单次日期写 `YYYY-MM-DD`。
- 排除日期为逗号分隔的 `YYYY-MM-DD`；没有排除日期时写 `~`。
- 颜色使用课间定义的中文色名，或 `0`–`11`。无法识别颜色时写 `~`，应用归一化为默认青绿。
- 提醒使用 `是` 或 `否`。无法识别时写 `~`，应用当前按默认开启处理。
- 字段中的 `|`、反斜线和换行分别转义为 `\|`、`\\` 和 `\n`。
- 多节课使用多行，每行一节；课程与截止日合计最多 2000 行。

未来 AI 的强制输出约定：只能输出 KJ1 课程记录、KJD1 截止日记录，或服务端定义的严格结构化操作；不得输出 Markdown、代码围栏、解释、标题或字段名。任何未识别内容写 `~`，不得猜测或省略字段。应用仍必须在导入前展示预览，让用户核对日期、星期、时间、周次和地址。

# KJD1 截止日格式

截止日与课程记录可以逐行混合传输。截止日固定格式为：

```text
KJD1|ID|标题|日期|时间|关联课程ID|详情|颜色|提醒
```

- 每行必须正好 9 个字段，字段顺序不可变化。
- `ID` 是稳定且唯一的截止日 ID；AI 更新或删除必须引用它。
- `日期` 使用 `YYYY-MM-DD`。
- `时间` 使用 `HH:mm`；未提供时间时必须写 `~`，不得自动写成 `00:00`。
- `关联课程ID` 可为课程 KJ1 的稳定 ID；独立截止日写 `~`。
- `详情` 未填写或未识别写 `~`。
- `颜色` 为 0–11；`提醒` 为 `1` 或 `0`。
- 文本字段中的 `|`、反斜杠和换行沿用本文件 KJ1 的转义规则。

示例：

```text
KJD1|deadline-001|线性代数作业|2026-09-10|23:59|course-linear-algebra|提交第三章习题|4|1
KJD1|deadline-002|社团报名|2026-09-12|~|~|~|7|0
```
